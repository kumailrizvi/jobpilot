# JobPilot AI Chrome Extension

## Install locally

1. Open Chrome
2. Go to `chrome://extensions`
3. Turn on Developer Mode
4. Click `Load unpacked`
5. Select this `extension` folder

## What it does

- Stores user-approved application details locally in Chrome
- Autofills common fields on Greenhouse, Lever, Ashby, Workday, Dayforce, LinkedIn
- Does not submit automatically
- Does not bypass CAPTCHA or verification
