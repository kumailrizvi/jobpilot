# Product Spec

## Name

JobPilot AI

## Target user

Job seekers applying to many roles who still want each application to be tailored.

## Core value

Turn one CV and candidate profile into high-quality job-specific applications.

## MVP features

### Candidate profile

- Background
- Work history
- Skills
- Education
- Target roles
- Locations
- Work authorization
- Generic application answers

### Job intake

- Paste JD
- Add source URL
- Add company
- Add platform

### AI generation

- Tailored resume
- Cover letter
- Screening answers
- Missing keyword analysis
- Fit score

### Review

- Edit generated text
- Approve
- Track status

### Apply

- MVP: user-assisted apply
- Later: platform-specific connectors

## Risky features to delay

- Full LinkedIn auto apply
- Fully autonomous Workday applications
- Generic-password account creation
- CAPTCHA bypass
